## 2026年10月19日播放入口修复

用户反馈播放三角灰色且无法点击。复现发现旧CSS使用 video:not([paused]) 判断播放状态，但 paused 是浏览器属性，不是HTML属性，导致中央播放按钮被误设为透明。初始按需加载又使原生控制条处于无源禁用状态，形成不可用的播放入口。

移除错误选择器，播放按钮由真实媒体事件与hidden状态控制。未点击时仅显示封面和可点击按钮，点击封面同样可以启动；启动后显示原生控制条。CSS与JS增加新的缓存参数。版本仍为V1.1.4修复补丁，文字、字号、视频文件与清晰度均未修改。

本地逐条鼠标点击10条视频均成功出首帧，解码尺寸正常且无媒体错误；暂停后继续、键盘启动及封面点击通过。发布核验记录见正式部署目录的播放修复验收.json。
